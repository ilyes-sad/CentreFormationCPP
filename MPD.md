# MPD - Modèle Physique de Données

## Table FORMATEUR
- ID_FORMATEUR NUMBER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY
- NOM VARCHAR2(100)
- PRENOM VARCHAR2(100)
- EMAIL VARCHAR2(150)
- TELEPHONE VARCHAR2(50)
- SPECIALITE VARCHAR2(100)
- DATE_EMBAUCHE DATE
- STATUS VARCHAR2(50)

## Table COURS
- ID_COURS NUMBER PRIMARY KEY
- INTITULE VARCHAR2(150)
- CATEGORIE VARCHAR2(100)
- NIVEAU VARCHAR2(50)
- ID_FORMATEUR NUMBER
- DUREE_HEURES NUMBER
- DATE_DEBUT DATE
- DATE_FIN DATE
- HEURE_DEBUT NUMBER DEFAULT 540
- HEURE_FIN NUMBER DEFAULT 1020
- CAPACITE NUMBER
- PROGRAMME CLOB

## Contraintes et objets Oracle
- FK_COURS_FORMATEUR : COURS.ID_FORMATEUR -> FORMATEUR.ID_FORMATEUR
- SEQUENCE : SEQ_FORMATEUR
- SEQUENCE : SEQ_COURS
- TRIGGER : TRG_FORMATEUR_ID
- TRIGGER : TRG_COURS_ID

## Schéma de relation
FORMATEUR 1 --- N COURS
